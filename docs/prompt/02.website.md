# 官网首页与文档站提示词提炼

> 来源：LytgOS2 项目窗口（2026-11-21，官网首页与 VitePress 文档站）。
>
> 使用方式：先替换 `[参考站路径]`、`[项目路径]`、`[域名]`、`[仓库地址]` 等占位符；截图作为附件提供，不在文档中内嵌。

## 1. 可复用提示词

### 1.1 理解参考站并确认改造范围

```text
理解 [参考站路径] 这个项目的代码。这个项目要做一个一模一样的首页：
1. 先只做理解，不改文件；
2. 分析首页结构、视觉层级、组件、文案、响应式和构建方式；
3. 列出需要我确认的问题和需要我提供的素材；
4. 给出可执行的改造清单和风险点。
```

### 1.2 落地位置、技术栈与域名

```text
按以下约束实现官网首页：
1. 放在 [项目路径]；
2. 使用 Vue/VitePress；
3. 域名是 [域名]，本地先用假域名；
4. 不只版式一样，文案也要对齐，但产品名改成 [产品名]；
5. 连同文档站一起做；
6. 品牌颜色和 Logo 选 [A/B] 方案；
7. 参考 [仓库地址]；
8. 其他按你的建议来；
9. 需要中英文切换，默认英文。
```

### 1.3 首页偏差修正

```text
列出当前首页与参考站的偏差，并逐项修正：
1. 解释 [AUDITABLE] 协议和 [TBD] 的含义；
2. 与 Demo 相关的条目先记住，后续有 Demo 时再追加；
3. 当前只在本地测试，不发布；描述差异先不强制对齐。
```

### 1.4 先跑起来再继续

```text
描述差异先不用改，先把网站跑起来给我看。
```

### 1.5 首页验收与文档站

```text
首页先按当前范围验收；保留后续可能调整的条目。
然后读取 [DOCS 目录] 下新增的文档，按以下意见调整：
1. [不需要改的项] 不用改；
2. 许可证对齐 [Apache 2.0]；
3. 网站文案可以重写；
4. 增加一个入口，点击后提示“还在建设中”。
```

### 1.6 技术文档与新定位

```text
你写吧，技术文档也按新定位收验：
- 官网定位与 1.0 基线保持一致；
- 不承诺未实现的能力；
- 安全边界、无认证部署限制和扩展范围写清楚。
```

### 1.7 中英文切换与默认语言

```text
为网站和文档站增加中英文切换，默认英文：
- 导航、页面结构、链接和元数据保持一致；
- 中文文案可重写，但不能改变产品定位和 1.0 范围；
- 本地预览时检查语言切换、深色模式和移动端布局。
```

### 1.8 本地预览与部署

```text
在本地启动网站，使用假域名 [域名] 预览：
1. 首页、文档站、中英文切换可用；
2. 移动端布局和深色模式正常；
3. 记录本地启动命令、端口和依赖；
4. 不提交构建产物和本地缓存。
```
